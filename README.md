💬 Firebase Chatroom App

Firebase Chatroom App is a simple Android chat application built with Kotlin and Jetpack Compose. The project demonstrates how Firebase can be integrated into a modern Android application to create a real-time chat experience.

Users can enter the chatroom, send messages, and view messages shared within the room. Firebase handles the backend data management and synchronization, allowing messages to be reflected in the chatroom without requiring a custom backend server.

✨ Features

* 💬 Shared Chatroom – Participate in a common chatroom.
* 📤 Send Messages – Send text messages to the chatroom.
* 🔄 Real-Time Updates – Receive newly added messages dynamically.
* ☁️ Firebase Integration – Use Firebase for cloud-based chat data.
* 📱 Jetpack Compose UI – Build the chat interface using Compose.
* ⚡ Dynamic Message List – Display chat messages as they are updated.
* 🎨 Clean Chat Interface – Simple and modern messaging UI.
* 🔗 Firebase Synchronization – Keep chat data synchronized across users.
